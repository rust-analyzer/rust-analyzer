Struct EditPlan 

Source 
struct EditPlan {
    changes: Vec<PlannedChange>,
}
Expand description

A validated batch of changes in the exact order in which it must execute.

Planning is deliberately separate from tree mutation. Once an EditPlan exists, execution does not need to reason about overlaps, dependencies, or source ordering.

fn build( changes: Vec<Change>, mappings: &SyntaxMapping, node_depth: impl FnMut(SyntaxNode) -> usize, ) -> Result<Self, InvalidEditPlan>

Validates raw editor changes and turns them into an execution schedule.

The input is first sorted in source order, dependent targets are then rewritten from their input trees into ancestor replacement trees. Finally, discarded changes are removed and the dependency forest is traversed in postorder. Independent roots and sibling changes are prioritized right to left.
