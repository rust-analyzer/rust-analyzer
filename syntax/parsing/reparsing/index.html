Module reparsing 

Source
Expand description

Implementation of incremental re-parsing.

We use two simple strategies for this:

  • if the edit modifies only a single token (like changing an identifier’s letter), we replace only this token.
  • otherwise, we search for the nearest {} block which contains the edit and try to parse only this block.
