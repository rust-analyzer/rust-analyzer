Module pool

Pool implements a basic custom thread pool inspired by the threadpool crate. When you spawn a task you specify a thread intent so the pool can schedule it to run on a thread with that intent. rust-analyzer uses this to prioritize work based on latency requirements.

The thread pool is implemented entirely using the threading utilities in crate::thread.
