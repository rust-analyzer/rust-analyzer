pub(crate) fn path_might_be_cyclic(path: &Path) -> bool
Expand description

Is path a symlink to a parent directory?

Including this path is guaranteed to cause an infinite loop. This heuristic is not sufficient to catch all symlink cycles (it’s possible to construct cycle using two or more symlinks), but it catches common cases.
